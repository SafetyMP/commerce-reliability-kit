# Code of conduct

Communicate respectfully, critique work rather than people, protect private information, and welcome good-faith questions and corrections. Harassment, threats, discriminatory abuse, doxxing, sexualized conduct, and deliberate disclosure of private merchant data are unacceptable. This policy covers project issues, reviews, discussions, and representations of the project. Participation does not imply vendor or company endorsement.

GitHub account SafetyMP is the current steward and may warn participants, remove content, restrict participation, or exclude participants for serious or repeated misconduct. Decisions should state a reason, protect confidentiality where practicable, and prohibit retaliation for good-faith reports. Conflicted reviewers should recuse.

No private project conduct contact or alternate maintainer has been established. Do not post private details in public issues. Use [GitHub's abuse reporting process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) for platform-policy concerns, including concerns involving the steward. This is a platform escalation, not a project-run independent appeal panel. Requests to reconsider ordinary moderation can be directed to the steward without exposing private evidence; no independent project appeal is promised.

This is original policy licensed with the project, not a claim to have adopted a third-party covenant. Vulnerabilities use the separate private route in [SECURITY.md](SECURITY.md).
